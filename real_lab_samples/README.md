# Real Enterprise SOC Lab Telemetry Samples

This directory provides un-flattened, authentic enterprise log samples captured from live SOC lab environments, demonstrating the exact schemas generated by production telemetry agents.

---

## Sample Telemetry Files

### 1. `windows_sysmon_process_creation.json`
* **Source:** Microsoft Sysmon (`Microsoft-Windows-Sysmon/Operational`)
* **Event ID:** 1 (Process Create)
* **Scenario:** Encoded PowerShell execution (`T1059.001`) emulating initial execution cradle.
* **Key Fields:** `win.eventdata.image`, `win.eventdata.commandLine`, `win.eventdata.parentImage`, `win.eventdata.hashes`, `win.eventdata.user`.

### 2. `windows_security_logon_4625.json`
* **Source:** Windows Security Auditing (`Security`)
* **Event ID:** 4625 (An account failed to log on) & 4624 (Successful logon)
* **Scenario:** RDP brute-force credential guessing attack (`T1110.001`).
* **Key Fields:** `win.eventdata.targetUserName`, `win.eventdata.ipAddress`, `win.eventdata.logonType`, `win.eventdata.status`, `win.eventdata.subStatus`.

### 3. `suricata_nids_eve.json`
* **Source:** Suricata Network Threat Detection Engine
* **Format:** Extensible Event Format (`eve.json`)
* **Scenario:** Nmap SYN stealth scan & service enumeration (`T1046`).
* **Key Fields:** `src_ip`, `dest_ip`, `proto`, `alert.signature_id`, `alert.signature`, `alert.category`, `alert.severity`.
